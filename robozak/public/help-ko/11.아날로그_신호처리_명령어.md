**AD()          변환()**

AD변환포트로부터 아날로그 신호를 디지털로 변환한다. 3000

![](11.아날로그%20신호처리%20명령어.files/image001.gif)

             -
영문구문 : AD (*[AD포트]*)

             -
한글구문 : 변환 (*[AD포트]*)

![](11.아날로그%20신호처리%20명령어.files/image002.gif)

MR-C3000 계열 컨트롤러에는 0번부터 7번까지의 총 8개의 AD변환 포트 (디지털입출력 포트 32번부터 39번까지) 가
있으며, 외부 센서 또는 기기로부터의 아날로그 신호를 디지털로 변환하여 읽어 들인다. *[AD포트]* 에는 0부터 7까지 숫자, 상수
또는 바이트형 변수를 사용한다.

 

![](11.아날로그%20신호처리%20명령어.files/image003.gif)

 다음 예제는 AD
1번 포트로부터 아날로그 신호를 입력 받아 그 값을 LCD 모듈에 출력하는 예제이다.

a AS BYTE                *'a라는

*'저장한다.*

- P1 버튼과 변경하고자 하는 ID번호(1, 2, 3, 4 중 하나) 키를 약 2초간 동시에 누른다.

*‘ID 체크하는 부분*

ELSEIF IR\_ID =

**GYRODIR         자이로방향**

자이로
센서처리 서보모터의 동작 방향을 설정한다. 3000

![](11.아날로그%20신호처리%20명령어.files/image001.gif)

             -
영문구문 : GYRODIR *[그룹지정], [모터n동작방향],……*

             -
한글구문 : 자이로방향 *[그룹지정], [모터n동작방향],……*

![](11.아날로그%20신호처리%20명령어.files/image002.gif)

MR-C3000 계열 컨트롤러의 AD입력 포트에 자이로 센서를 연결하여 자이로 센서 에 의한 처리 값을 포트에 연결된 각 서보모터에
반영할 때, 처리되는 동작 방향을 설정한다. 자이로 센서는 총 4개까지(자이로 포트 4개) 연결이 가능하며, 각 자이로 센서의 연결은 다음과 같다.

 

![](11.아날로그%20신호처리%20명령어.files/image015.gif)

|  |  |
| --- | --- |
| **MR-C3000 계열 컨트롤러**  **AD 포트 번호 (디지털입출력 포트 번호)** | **자이로 포트** |
| 0번 포트 (32번 포트) | 자이로 1번 채널 출력 포트 |
| 1번 포트 (33번 포트) | 자이로 2번 채널 출력 포트 |

 자이로 센서의 입력 값은 기준 값에서 회전하는 각도에 따라 좌우로 값이 변경되므로, 이에 대한 자이로 센서의 값을
서보모터에 반영할 때, GYRODIR 명령어를 사용하여 현재 서보모터 값에 자이로 입력 값을 가감할 지를 결정한다.

 *[모터n동작방향]*은
“0” 또는 “1”을 사용하며, “1”은 자이로 입력값이 증가하면 현재 서보모터의 값을 증가시키고, “0”은 감소시킨다.

 

![](11.아날로그%20신호처리%20명령어.files/image003.gif)

**GYROSET        자이로설정**

연결된
각 서보모터에 반영할 자이로 센서를 설정한다. 3000

![](11.아날로그%20신호처리%20명령어.files/image001.gif)

             -
영문구문 : GYROSET *[그룹지정], [모터n자이로],……*

             -
한글구문 : 자이로설정 *[그룹지정], [모터n자이로],……*

 

![](11.아날로그%20신호처리%20명령어.files/image002.gif)

MR-C3000 계열 컨트롤러에 연결할 수 있는 자이로는 총 4개이며, 컨트롤러에 연결된 서보모터 각각에 반영할 자이로 센서의
포트를 설정한다.

*[모터n자이로]*는 1부터 4에 해당되는 해당 서보모터에 반영될 자이로 센서의
포트 번호이다. 만약 0을 설정하게 되면 자이로 센서의 입력을 사용하지 않는다.

 

![](11.아날로그%20신호처리%20명령어.files/image003.gif)

             GYROSET
G6B, 1, 1, 2, 2, 0, 0

*‘6번 서보모터는 자이로 센서 1번의 값을 입력받아 처리한다.*

*‘7번 서보모터는 자이로 센서 1번의 값을 입력받아 처리한다.*

*‘8번 서보모터는 자이로 센서 2번의 값을 입력받아 처리한다.*

*‘9번 서보모터는 자이로 센서 2번의 값을 입력받아 처리한다.*

*‘10번, 11번 서보모터는 자이로 센서를 사용하지 않는다.*

 

  

 

**GYROSENSE          자이로감도**

연결된
각 서보모터에 반영할 자이로 센서를 설정한다. 3000

![](11.아날로그%20신호처리%20명령어.files/image001.gif)

             -
영문구문 : GYROSENSE *[그룹지정], [모터n자이로감도],……*

             -
한글구문 : 자이로감도 *[그룹지정], [모터n자이로감도],……*

![](11.아날로그%20신호처리%20명령어.files/image002.gif)

MR-C3000 계열 컨트롤러에 연결할 수 있는 자이로는 총 4개이며, 컨트롤러에 연결된 서보모터 각각에 반영할 자이로 센서의
감도를 설정한다.

*[모터n자이로감도]*는 0부터 255사이의 숫자, 상수를 사용하며, 0은 자이로
센서의 입력값을 전혀 반영하지 않으며 값이 커질수록 서보모터는 설정된 장로 센서의 입력값에 의한 빠른 반응을 보이게 된다.

 

![](11.아날로그%20신호처리%20명령어.files/image003.gif)

             GYROSENSE
G6A, 100, 100, 255, 255, 50, 50

*‘0번, 1번 서보모터는 자이로 감도를 100으로 설정한다.*

*‘2번, 3번 서보모터는 자이로 감도를 최대(255)로 설정한다.*

*‘4번, 5번 서보모터는 자이로 감도를 작게(50) 설정한다.*

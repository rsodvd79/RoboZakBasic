**KEYIN()      키보드()**

여러 개의
키(아날로그 키패드)를 입력받는다. 3000

![](KEYIN.files/image001.gif)

             -
영문구문 : KEYIN(*[아날로그포트번호], [키갯수]*)

             -
한글구문 : 키보드(*[아날로그포트번호], [키갯수]*)

 

![](KEYIN.files/image002.gif)

 MR-C3000 계열
컨트롤러의 AD변환 포트(아날로그포트)를 통해 푸시버튼을 최대 16개로 구성된 아날로그 전압 분배회로에 의해 입력된 버튼의 값을 읽어 들인다.

 *[아날로그포트번호]*는
0부터 7까지 숫자, 상수 또는 바이트형 변수가 가능하고, *[키갯수]*는 1부터 16까지의 숫자, 상수 또는 바이트형 변수가 가능하다.

 읽어들인 버튼의 값은
0부터 16까지이며, 0은 키가 전혀 눌리지 않는 상태이고, 1부터16은 해당 수는 버튼이 눌린 경우이다.

 

![](KEYIN.files/image003.gif)

DIM K AS BYTE

 

K = KEYIN(0,
16)   *‘AD0번포트에 연결된 16개의 키(푸시버튼)로 구성된*

*‘아날로그 키패드의 값을 K에 입력한다.*

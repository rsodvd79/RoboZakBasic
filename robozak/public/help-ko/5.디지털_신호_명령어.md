**디지털 신호 입출력(I/O) 명령어**

 

 미니로봇 컨트롤러는
MR-C2000계열의 경우 최대 12개, MR-C3000계열의 경우 최대 40개의 디지털 신호를 주고 받을 수 있는 입출력 포트(I/O
Port)가 있으며, 이 포트를 통하여 다양한 기능을 수행한다. 디지털 신호 입출력 포트에 대해서는 “미니로봇 컨트롤러 설명”을 참조한다.

 

**IN()      입력()**

포트로부터
디지털 신호의 값을 읽어들인다.

![](5.디지털%20신호%20명령어.files/image001.gif)

 

             -
영문구문 : IN(*[포트번호]*)

             -
한글구문 : 입력(*[포트번호]*)

 

![](5.디지털%20신호%20명령어.files/image002.gif)

미니로봇컨트롤러의 포트를
통해서 신호를 입력 받아 값을 변수에 저장한다. 포트에 입력된 값은 0 또는 1의 값이며, 사용되는 변수에는 바이트형,
정수형의 변수 사용이 가능하며 이때는 마지막 0번째 비트의 값만이 유효하다. 가능 효율적인 방법은 바이트형
변수의 비트 지정으로 값을 입력받는다. 포트에 어떤 장치도 연결되어 있지 않는 상태에서 신호의 값을 읽어들이면 전혀 다른 값이 입력될 수 있으므로
주의한다.

 

![](5.디지털%20신호%20명령어.files/image003.gif)

DIM A AS BYTE

 A =
IN(0)     *'0번 포트에 신호(스위치 또는 센서)를 받아 A 변수에 넣는다.*

  

 

**OUT     출력**

포트에
디지털 신호를 내보낸다.

![](5.디지털%20신호%20명령어.files/image001.gif)

 

             -
영문구문 : OUT *[포트번호]*, *[출력값]*

             -
한글구문 : 출력 *[포트번호]*, *[출력값]*

 

![](5.디지털%20신호%20명령어.files/image002.gif)

미니로봇컨트롤러의 포트를
통해서 신호를 내보낸다. 0(LOW)의 값을 내보내면 0V의 신호를 출력하며, 1(HIGH)의 값을 내보내면
+5V의 신호가 출력된다. [출력값]에는 숫자(0 또는 1), 상수, 변수 등의 사용이 가능하며, 출력포트 또한 0 또는 1의 값만이 유효하기
때문에 [출력값]에 변수의 비트 지정을 사용할 수 있다.

 

![](5.디지털%20신호%20명령어.files/image003.gif)

다음 예제는 0번포트에 푸시버튼(Push Button)을 연결하고 3번 포트를 LED를 연결하여 포트 입출력을 시험하기 위한 회로에 대해
작성되었다.

 

DIM A AS INTEGER

 

A =
0              
                       *'A
변수를 초기화*

START: A =
IN(0)                                   *'버튼
상태를 읽어들임*

                              
                    *'A.0
= IN(0) 로 사용할 수 있다.*

IF A = 1 THEN                             *'버튼이
안 눌려졌으면*

   OUT 3,
0                              *'LED를
끔*

ELSE                
                    *'그렇지
않고, 버튼이 눌려졌으면*

   OUT 3,
1                              *'LED를
켬*

ENDIF

GOTO START                            *'다시
버튼을 체크*

 

**BYTEIN()    바이트입력()**

바이트
단위의 입력포트로부터 신호를 읽어들인다.

![](5.디지털%20신호%20명령어.files/image001.gif)

 

             -
영문구문 : BYTEIN(*[바이트포트번호]*)

             -
한글구문 : 바이트입력(*[바이트포트번호]*)

 

![](5.디지털%20신호%20명령어.files/image002.gif)

미니로봇컨트롤러의 포트는 IN(입력)/OUT(출력) 명령어에서처럼 한 비트단위로 신호를 입출력할 수 있지만, 어떤 경우에는 한 단위(여기서는 8개
포트 단위의 바이트포트)로 입출력할 필요가 있다. 미니로봇컨트롤러는 각 포트에 대해서 다음과 같은 바이트포트로 설정되어 있다.

 

MR-C2000계열의 컨트롤러)

 

|  |  |
| --- | --- |
| **바이트포트** | **포트** |
| 0 | 0번부터 7번 포트 (0번 포트가 바이트포트의 하위) |
| 1 | 8번부터 11번 포트 (8번 포트가 바이트포트의 하위) |

 

MR-C3000계열의 컨트롤러)

 

|  |  |
| --- | --- |
| **바이트포트** | **포트** |
| 0 | 0번부터 7번 포트 (0번 포트가 바이트포트의 하위) |
| 1 | 8번부터 15번 포트 (8번 포트가 바이트포트의 하위) |
| 2 | 16번부터 23번 포트 (16번 포트가 바이트포트의 하위) |
| 3 | 24번부터 31번 포트 (24번 포트가 바이트포트의 하위) |
| 4 | 32번부터 39번 포트 (32번 포트가 바이트포트의 하위) |

 

BYTEIN(바이트입력)명령어는 미니로봇컨트롤러의 바이트 단위의 입력포트를 통해서 신호를 입력 받아 값을 변수에 저장한다.
변수는 바이트형, 정수형으로 선언되어 있어야 한다.

 

![](5.디지털%20신호%20명령어.files/image003.gif)

 A
= BYTEIN(0)*'0번
포트에서 7번 포트의 신호가 모두*

*‘**A 변수에 입력된다.*

 

**BYTEOUT   바이트출력**

바이트
단위로 포트에 신호를 내보낸다.

![](5.디지털%20신호%20명령어.files/image001.gif)

 

             -
영문구문 : BYTEOUT *[바이트포트번호]*, *[출력값]*

             -
한글구문 : 바이트출력 *[바이트포트번호]*, *[출력값]*

 

![](5.디지털%20신호%20명령어.files/image002.gif)

미니로봇컨트롤러의 바이트

0-255사이의 숫자나 상수 또는 바이트 변수를 사용한다.

 

![](5.디지털%20신호%20명령어.files/image003.gif)

BYTEOUT

*'1,3,5,7번 포트에

**INKEY  키입력**

입력포트로부터
키(스위치) 값을 입력 받는다. 2000

![](5.디지털%20신호%20명령어.files/image001.gif)

             -
영문구문 : INKEY (*[포트번호]*)

             -
한글구문 : 키입력 (*[포트번호]*)

 

![](5.디지털%20신호%20명령어.files/image002.gif)

입력포트를 통해서 버튼과
같은 키를 사용하고자 할 때 사용자는 실제 키를 한번만 누르는 것 같지만 전기적/기계적으로는 수없이 많은 횟수만큼
스위치가 눌려지게 된다. 이러한 현상을 채터링(Chattring)현상이라고 하며, 이는 잘못된 키 값을 읽어올 수 있으므로, 채터링 방지 부가
회로가 필요하다. 미니로봇컨트롤러는 별도의 부가회로 없이 소프트웨어적으로 채터링 방지가 구현되어 있으며, 이를 사용하기 위해서 입력포트에 대해
간단히 키입력(INKEY) 명령어를 사용하면 된다.

 

![](5.디지털%20신호%20명령어.files/image003.gif)

0번 포트에 연결된 키(스위치)의 누름 상태를 A변수에 저장한다.

 

DIM A AS BYTE

 

A = INKEY(0)

 

  

**STATE()          출력상태()**

출력포트의
현재 출력상태 값을 읽어온다.

![](5.디지털%20신호%20명령어.files/image001.gif)

             -
영문구문 : STATE (*[포트번호]*)

             -
한글구문 : 출력상태 (*[포트번호]*)

 

![](5.디지털%20신호%20명령어.files/image002.gif)

출력포트를 통해서 신호를
내보낸 후 그 포트의 값의 상태를 알려고 할 때는 다시 입력(IN)함수를 사용해서는 안되고, 출력포트의 상태를 알아내는
출력상태(STATE)함수를 사용하여야 한다.

 

![](5.디지털%20신호%20명령어.files/image003.gif)

 미니로봇 컨트롤러의
1번 포트의 출력상태를 알아보는 프로그램의 예이다.

 

DIM A AS BYTE

 

OUT 1, 1

A = STATE(1)*'
A = 1*

OUT 1, 0

A = STATE(1)*'
A = 0*

**KEYIN()      키보드()**

여러 개의
키(아날로그 키패드)를 입력받는다. 3000

![](5.디지털%20신호%20명령어.files/image001.gif)

             -
영문구문 : KEYIN(*[아날로그포트번호], [키갯수]*)

             -
한글구문 : 키보드(*[아날로그포트번호], [키갯수]*)

 

![](5.디지털%20신호%20명령어.files/image002.gif)

 MR-C3000 계열
컨트롤러의 AD변환 포트(아날로그포트)를 통해 푸시버튼을 최대 16개로 구성된 아날로그 전압 분배회로에 의해 입력된 버튼의 값을 읽어 들인다.

 *[아날로그포트번호]*는
0부터 7까지 숫자, 상수 또는 바이트형 변수가 가능하고, *[키갯수]*는 1부터 16까지의 숫자, 상수 또는 바이트형 변수가 가능하다.

 읽어들인 버튼의 값은
0부터 16까지이며, 0은 키가 전혀 눌리지 않는 상태이고, 1부터16은 해당 수는 버튼이 눌린 경우이다.

 

![](5.디지털%20신호%20명령어.files/image003.gif)

DIM K AS BYTE

 

K = KEYIN(0,
16)   *‘AD0번포트에 연결된 16개의 키(푸시버튼)로 구성된*

*‘아날로그 키패드의 값을 K에 입력한다.*

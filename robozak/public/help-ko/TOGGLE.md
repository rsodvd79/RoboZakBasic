**TOGGLE          반전**

출력포트
신호를 반전한다.

![](TOGGLE.files/image001.gif)

             -
영문구문 : TOGGLE *[포트번호]*

             -
한글구문 : 반전 *[포트번호]*

 

![](TOGGLE.files/image002.gif)

|  |
| --- |
|  |
|  |  |

  
출력포트의 출력신호를 반전시킨다. 즉, 출력포트 신호가 0(LOW)이면 1(HIGH)로, 1(HIGH)이면
0(LOW)으로 반전된다.

 *[포트번호]*는
숫자, 상수, 변수 등이 사용가능하다.

 

![](TOGGLE.files/image004.gif)

OUT 3, 1          *'3번 포트에
1신호를 내보낸다.*

TOGGLE 3        *'3번 포트의 신호를 반전(1에서
0으로)시킨다.*

**PULSE       펄스**

Invia un segnale a impulso alla porta di uscita.

![](PULSE.files/image001.gif)

             -
Sintassi inglese : PULSE *[numero porta]*

             -
Sintassi coreana : 펄스 *[numero porta]*

 

![](PULSE.files/image002.gif)

Invia un segnale a impulso alla porta di uscita per un tempo brevissimo (5㎲). Il segnale a impulso serve per inviare un segnale all'esterno.

|  |
| --- |
|  |
|  |  |

 *[numero porta]* può essere un numero, una costante, una variabile, ecc.

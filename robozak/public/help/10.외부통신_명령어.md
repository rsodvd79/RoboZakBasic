**Descrizione dei comandi di comunicazione esterna**

 

**Comunicazione esterna dei controller della serie MR-C2000)**

 

 I controller della serie MR-C2000 possono usare due metodi per comunicare con l'esterno. Uno è la comunicazione seriale (Serial Communication) di tipo RS232, l'altro utilizza il miniBUS proprietario.

 Innanzitutto, la comunicazione seriale RS232 permette di scambiare dati con normali PC che supportano RS232 o con altri microcontroller (compresi altri controller miniROBOT). Inoltre, poiché i dati si possono scambiare via cavo o senza fili (con moduli RF), presenta molti vantaggi. Per la comunicazione RS232 servono 3 fili: basta collegare tra loro trasmissione (TX), ricezione (RX) e massa (GND).

|  |
| --- |
|  |
|  |  |

 

 Per riferimento, per il collegamento a un normale PC serve un circuito aggiuntivo di conversione di tensione, come un MAX232.

|  |
| --- |
|  |
|  |  |

  
 Il metodo minibus, mentre la comunicazione RS232 usa 3 fili, scambia i dati con 2 fili: la linea del segnale BUS e la massa (GND).

 

 Poiché il minibus invia e riceve dati su un solo filo, i controller devono scambiarsi i dati secondo regole precise per ottenere una trasmissione corretta. Un esempio di trasmissione dati tramite minibus è il modulo LCD, in cui il controller montato sul modulo LCD usa il minibus solo per la ricezione.

 

**Comunicazione esterna dei controller della serie MR-C3000)**

 

I controller della serie MR-C3000 includono la funzione di comunicazione RS232 ad alta velocità con dispositivi o componenti esterni. Tuttavia, la serie MR-C3000 non supporta la comunicazione miniBUS. La comunicazione RS232 è possibile con gli stessi collegamenti dell'MR-C2000, fino a una velocità massima di 115.200bps.

 

**RX       수신**

Riceve un segnale RS232 tramite la porta RX. 2000

![](10.외부통신%20명령어.files/image003.gif)

             -
Sintassi inglese : RX *[velocità porta], [variabile di ricezione], [etichetta gestione errore di ricezione]*

             -
Sintassi coreana : 수신 *[velocità porta], [variabile di ricezione], [etichetta gestione errore di ricezione]*

 

![](10.외부통신%20명령어.files/image004.gif)

Riceve dati in modalità RS232 tramite la porta 9 dei controller della serie MR-C2000. *[velocità porta]* è un numero o una costante da 1 a 4, con il seguente significato.

 

|  |  |
| --- | --- |
| **Numero** | **Impostazione porta** |
| 1 | 1200bps, 8Bit data, No parity, 1 Stop bit |
| 2 | 2400bps, 8Bit data, No parity, 1 Stop bit |
| 3 | 2400bps, 8Bit data, No parity, 1 Stop bit |
| 4 | 4800bps, 8Bit data, No parity, 1 Stop bit |

 

 *[variabile di ricezione]* è la variabile in cui salvare i dati ricevuti; deve essere una variabile di tipo byte già dichiarata.

 *[etichetta gestione errore di ricezione]* è l'etichetta da cui inizia la parte di codice eseguita se non sono stati ricevuti dati (cioè il buffer di comunicazione è vuoto). Un programma che attende finché non arrivano dati dalla porta RS232 si può scrivere così:

 

Retry:

             RX
 4,  A,  Retry

 *Nei controller della serie MR-C3000, per ricevere segnali RS232 si usa il comando ERX(데이타수신) al posto del comando RX(수신).*

 

![](10.외부통신%20명령어.files/image005.gif)

 Il seguente esempio è un programma che, se attraverso il terminale RS232 collegato all'esterno arriva il valore del codice ASCII &h80 (esadecimale), accende il LED della porta 0, altrimenti lo spegne.

 

             DIM 
A  AS  BYTE

 

Retry:   RX 4, A, Retry

             IF
A = &h80 THEN

                           OUT
0, 0

             ELSE

                           OUT
0, 1

             ENDIF

             GOTO
Retry

 

  

**TX       송신**

Trasmette un segnale RS232 tramite la porta TX. 2000

![](10.외부통신%20명령어.files/image003.gif)

             -
Sintassi inglese : TX *[velocità porta], [dati]*

             -
Sintassi coreana : 송신 *[velocità porta], [dati]*

 

![](10.외부통신%20명령어.files/image004.gif)

Trasmette dati in modalità RS232 tramite la porta 10 dei controller della serie MR-C2000. *[velocità porta]* è un numero o una costante da 1 a 4, con il seguente significato.

 

|  |  |
| --- | --- |
| **Numero** | **Impostazione porta** |
| 1 | 1200bps, 8Bit data, No parity, 1 Stop bit |
| 2 | 2400bps, 8Bit data, No parity, 1 Stop bit |
| 3 | 2400bps, 8Bit data, No parity, 1 Stop bit |
| 4 | 4800bps, 8Bit data, No parity, 1 Stop bit |

 

 *[dati]* è il valore dei dati inviati tramite la porta di trasmissione. *[dati]* può essere un numero, una costante, una variabile, ecc. Per trasmettere il carattere "A" bisogna inviare il codice ASCII corrispondente a "A", cosa che si può fare semplicemente così:

 

DIM I AS BYTE

 

I = "A"

TX 4, I

 

 Cioè, assegnando una stringa a una variabile, alla variabile viene assegnato il valore del codice ASCII del primo carattere della stringa.

*Nei controller della serie MR-C3000, per trasmettere segnali RS232 si usa il comando ETX(데이타송신) al posto del comando TX(송신).*

 

![](10.외부통신%20명령어.files/image005.gif)

 Il seguente esempio è un programma che trasmette continuamente il valore del tasto della porta byte 0 tramite il terminale RS232 collegato all'esterno.

 

             DIM 
A  AS  BYTE

 

 Main:

             A
= BYTEIN(0)

             TX 
4, A

             GOTO
Main

**Tipi di numero**

 I tipi di numero sono byte (BYTE) e intero (INTEGER); l'intervallo di valori di ciascun tipo è indicato nella tabella.

|  |  |  |
| --- | --- | --- |
| **Tipo di numero** | **Dimensione** | **Intervallo** |
| Byte (BYTE) | 1 byte (8 bit) | 0-255 |
| Intero (INTEGER) | 2 byte (16 bit) | 0-65535 |

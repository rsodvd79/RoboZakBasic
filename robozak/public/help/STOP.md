**STOP/RUN 정지/실행**

Mette in pausa / riprende l'esecuzione del programma.

![](STOP.files/image001.gif)

 

             -
Sintassi inglese : STOP/RUN

             -
Sintassi coreana : 정지/실행

 

![](STOP.files/image002.gif)

 

Si usa per mettere in pausa o riprendere l'esecuzione del programma; quando il programma è in pausa, per farlo ripartire occorre usare il comando RUN (실행).

**Comandi di ingresso/uscita (I/O) di segnali digitali**

 

 Il mini controller robot dispone di porte di ingresso/uscita (I/O Port) in grado di scambiare segnali digitali: fino a 12 nella serie MR-C2000 e fino a 40 nella serie MR-C3000; attraverso queste porte svolge varie funzioni. Per le porte di ingresso/uscita di segnali digitali si veda la “Descrizione del mini controller robot”.

 

**IN()      입력()**

Legge il valore di un segnale digitale da una porta.

![](5.디지털%20신호%20명령어.files/image001.gif)

 

             -
Sintassi inglese : IN(*[numero porta]*)

             -
Sintassi coreana : 입력(*[numero porta]*)

 

![](5.디지털%20신호%20명령어.files/image002.gif)

Riceve un segnale tramite una porta del mini controller robot e ne memorizza il valore in una variabile. Il valore presente sulla porta è 0 oppure 1; si possono usare variabili di tipo byte o intero, e in tal caso è valido solo il valore dell'ultimo bit, il bit 0. Il modo più efficiente è acquisire il valore tramite la specifica del bit di una variabile di tipo byte. Attenzione: se si legge il valore del segnale quando alla porta non è collegato alcun dispositivo, possono essere letti valori del tutto casuali.

 

![](5.디지털%20신호%20명령어.files/image003.gif)

DIM A AS BYTE

 A =
IN(0)     *'Riceve il segnale (interruttore o sensore) sulla porta 0 e lo mette nella variabile A.*

  

 

**OUT     출력**

Invia un segnale digitale a una porta.

![](5.디지털%20신호%20명령어.files/image001.gif)

 

             -
Sintassi inglese : OUT *[numero porta]*, *[valore di uscita]*

             -
Sintassi coreana : 출력 *[numero porta]*, *[valore di uscita]*

 

![](5.디지털%20신호%20명령어.files/image002.gif)

Invia un segnale tramite una porta del mini controller robot. Inviando il valore 0 (LOW) si emette un segnale a 0V, mentre inviando il valore 1 (HIGH) si emette un segnale a +5V. Come [valore di uscita] si possono usare numeri (0 o 1), costanti, variabili e così via; poiché anche per la porta di uscita è valido solo il valore 0 o 1, come [valore di uscita] si può usare la specifica del bit di una variabile.

 

![](5.디지털%20신호%20명령어.files/image003.gif)

**INKEY  키입력**

Riceve il valore di un tasto (interruttore) da una porta di ingresso. 2000

![](5.디지털%20신호%20명령어.files/image001.gif)

             -
Sintassi inglese : INKEY (*[numero porta]*)

             -
Sintassi coreana : 키입력 (*[numero porta]*)

 

![](5.디지털%20신호%20명령어.files/image002.gif)

Quando si vuole usare un tasto, come un pulsante, tramite una porta di ingresso, l'utente crede di premere il tasto una sola volta, ma elettricamente/meccanicamente l'interruttore viene premuto innumerevoli volte. Questo fenomeno si chiama rimbalzo (chattering) e può portare a leggere valori errati del tasto, quindi sarebbe necessario un circuito aggiuntivo anti-rimbalzo. Il mini controller robot implementa l'anti-rimbalzo via software, senza alcun circuito aggiuntivo, e per usarlo basta applicare alla porta di ingresso il comando INKEY (키입력).

 

![](5.디지털%20신호%20명령어.files/image003.gif)

Memorizza nella variabile A lo stato di pressione del tasto (interruttore) collegato alla porta 0.

 

DIM A AS BYTE

 

A = INKEY(0)

![](5.디지털%20신호%20명령어.files/image002.gif)

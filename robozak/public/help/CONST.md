**CONST      상수**

Dichiara una costante.

![](CONST.files/image001.gif)

- Sintassi inglese : CONST [nome costante] = numero

    - Sintassi coreana : 상수 [nome costante] = numero

 

![](CONST.files/image002.gif)

Si usa quando conviene identificare con un nome un numero usato in modo specifico, per semplificare la scrittura del programma. Usare una costante, rispetto a un semplice numero o a una variabile, offre i seguenti vantaggi.

 

             ①
Una costante va definita una sola volta e può essere usata in tutto il programma.

             ②
Una costante non può essere modificata per errore.

             ③
Usando le costanti, le modifiche diventano più semplici.

             ④
Un programma che usa costanti non occupa spazio in memoria,

          
quindi genera un codice oggetto più efficiente rispetto all'uso di variabili.

 

![](CONST.files/image003.gif)

 

CONST OFF = 0          *'Dichiara la costante OFF = 0*

CONST A = &HB1001                  *'Dichiara A come costante decimale 9*

상수 참 =
1              
             *'Dichiara la costante 참 (vero) = 1*

상수 거짓 =
0                          *'Dichiara la costante 거짓 (falso) = 0*

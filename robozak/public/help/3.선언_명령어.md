**Descrizione dei comandi di dichiarazione**

Sono i comandi usati in roboBASIC per dichiarare variabili e costanti, e si usano insieme ai dichiaratori di tipo.

 

**DIM ... AS       선언
... 는**

Dichiara una variabile.

 

![](3.선언%20명령어.files/image001.gif)

 

① Dichiarazione di una singola variabile :

     - Sintassi inglese : DIM [nome variabile] AS [tipo variabile]

     - Sintassi coreana : 선언 [nome variabile] 는 [tipo variabile]

 

② Dichiarazione di più variabili :

     - Sintassi inglese : DIM [nome variabile] AS [tipo variabile], [nome variabile]
AS [tipo variabile], …..

     - Sintassi coreana : 선언 [nome variabile] 는 [tipo variabile], [nome variabile]
는 [tipo variabile], …..

 

![](3.선언%20명령어.files/image002.gif)

 

 Le variabili usate in roboBASIC devono prima essere dichiarate con il comando DIM. La dichiarazione di una variabile con DIM indica sempre il tipo tramite AS. Nei nomi delle variabili da dichiarare, per le lettere inglesi non c'è distinzione tra maiuscole e minuscole, e non si può dichiarare due volte lo stesso nome di variabile.

 Nei programmi per robot le variabili si usano per ricevere valori di sensori o valori di conversione analogica ed elaborarli in base al valore. Un uso appropriato delle variabili permette quindi di scrivere programmi efficaci; il numero di variabili utilizzabili è fissato in base al tipo di controller del robot.

 La serie MR-C2000 può usare variabili per un totale di 30 byte, mentre la serie MR-C3000 per un totale di 256 byte. Una variabile di tipo byte occupa 1 byte e una di tipo intero 2 byte; si consiglia quindi di dichiarare il tipo appropriato in base all'intervallo di utilizzo, per sfruttare al massimo le variabili disponibili.

 

![](3.선언%20명령어.files/image003.gif)

             DIM
I AS INTEGER                       *'Dichiara I come intero*

             DIM
J AS BYTE                         *'Dichiara J come byte*

             선언
K 는 정수                        *'Dichiara K come intero*

             선언
모터\_1 는 바이트, 모터\_2 는 바이트

                                                        
       *'Dichiara 모터\_1 e 모터\_2 come byte*

 

**CONST      상수**

Dichiara una costante.

 

![](3.선언%20명령어.files/image001.gif)

 

- Sintassi inglese : CONST [nome costante] = numero

    - Sintassi coreana : 상수 [nome costante] = numero

 

![](3.선언%20명령어.files/image002.gif)

 

Si usa quando è comodo, nella scrittura del programma, identificare con un semplice nome un numero usato in modo specifico come costante. Usare una costante, rispetto a un numero semplice o a una variabile, offre i seguenti vantaggi.

 

             ① Una costante va definita una sola volta e può essere usata in tutto il programma.

             ② Una costante non può essere modificata per distrazione.

             ③ Usando le costanti le modifiche diventano più facili.

             ④ Un programma che usa costanti non occupa spazio di memoria,

          
quindi genera un codice oggetto più efficiente rispetto all'uso di variabili.

 

![](3.선언%20명령어.files/image003.gif)

 

CONST OFF = 0          *'Dichiara la costante OFF = 0*

CONST A = &HB1001                  *'Dichiara A come costante di valore decimale 9*

상수 참 =
1              
             *'Dichiara la costante 참 (vero) = 1*

상수 거짓 =
0                          *'Dichiara la costante 거짓 (falso) = 0*

**Espressioni e operatori**

 Il set di caratteri di roboBASIC è composto da hangul (inclusi tutti i caratteri hangul/hanja supportati da Microsoft Windows), lettere inglesi (A-Z, a-z), numeri (0-9) e alcuni caratteri speciali.  Inoltre, i caratteri seguenti hanno un significato speciale in roboBASIC.

 

 

|  |  |
| --- | --- |
| **Carattere** | **Significato** |
| + | Simbolo di addizione |
| - | Simbolo di sottrazione |
| \* | Simbolo di moltiplicazione |
| / | Simbolo di divisione |
| % | Simbolo di resto |
| . | Simbolo di specifica del bit |
| & | Simbolo di base numerica |
| ?? | Simbolo di commento |
| ?? | Simbolo di stringa |
| : | Simbolo di etichetta |
| = | Uguale (operatore relazionale) o simbolo di assegnazione |
| < | Disuguaglianza (minore di) |
| > | Disuguaglianza (maggiore di) |
| << | Simbolo di shift a sinistra dei bit |
| >> | Simbolo di shift a destra dei bit |

Un'espressione può essere composta da un valore ottenuto combinando tra loro costanti, variabili, numeri, ecc. mediante operatori. Gli operatori eseguono operazioni aritmetiche o logiche sui valori dati. In roboBASIC gli operatori si possono classificare come segue.

 

|  |  |
| --- | --- |
| **Categoria** | **Funzione** |
| Operatori aritmetici | Eseguono calcoli aritmetici. |
| Operatori relazionali | Confrontano valori numerici. |
| Operatori logici | Confrontano condizioni composte o eseguono operazioni sui bit. |
| Operatori sui bit | Manipolano i bit o eseguono operazioni sui bit. |

 

**Operatori aritmetici**

 Gli operatori aritmetici sono simboli usati per eseguire calcoli aritmetici; si possono usare i simboli aritmetici dei normali linguaggi BASIC: addizione (+), sottrazione (-), moltiplicazione (\*), divisione (/), resto (% o MOD), ecc. Nelle operazioni aritmetiche roboBASIC presenta due differenze da ricordare rispetto ai normali linguaggi BASIC.

 

In primo luogo, ***gli operatori non hanno priorità.***

 Non si possono usare le parentesi ( ) per stabilire a piacere l'ordine delle operazioni, e il calcolo aritmetico viene eseguito secondo l'ordine in cui compaiono gli operatori, indipendentemente dalla loro precedenza. Ad esempio, A + B \* C in un normale BASIC moltiplica prima B e C e poi somma A al risultato, mentre in roboBASIC si somma prima A e B e poi si moltiplica il risultato per C.

 

Es.) Con A = 1, B = 2, C = 3.

 

BASIC normale)

                           A
+ B \* C =  1 + 2 \* 3 = 1 + 6 = 7

roboBASIC)

                           A
+ B \* C =  1 + 2 \* 3 = 3 \* 3 = 9

 

In secondo luogo, ***usando calcoli aritmetici troppo complessi possono verificarsi errori imprevisti.***

 

 In tal caso basta suddividere il calcolo in 2-3 passaggi.

 

Esempio di calcolo aritmetico)

 

  D = A \* B + C                            (uso corretto)

  F = A \* B / C \* D + E   (evitare calcoli troppo complessi.)

 

In terzo luogo, ***poiché roboBASIC supporta solo i tipi byte e intero, nelle operazioni di divisione la parte decimale del risultato viene ignorata.***

 

 Per l'operazione di resto si usa l'operatore di resto % o MOD, che fornisce come risultato il resto e non il quoziente.

 

**Operatori relazionali**

 Gli operatori relazionali si usano per confrontare due valori. Il risultato del confronto è "vero" (TRUE) o "falso" (FALSE) e viene usato nell'istruzione IF per controllare il flusso del programma.

 

|  |  |  |
| --- | --- | --- |
| **Operatore** | **Relazione** | **Espressione** |
| = | Uguale. | X = Y |
| <> | Diverso. | X <> Y |
| < | Minore di. | X < Y |
| > | Maggiore di. | X > Y |
| <= | Minore o uguale a. | X <= Y |
| >= | Maggiore o uguale a. | X >= Y |

 

 Se in una stessa espressione sono combinati operatori aritmetici e logici, le operazioni aritmetiche vengono eseguite per prime.

 

**Operatori logici**

 Gli operatori logici si usano per confrontare condizioni composte e restituiscono come risultato "vero" o "falso". Questo risultato può essere usato nell'istruzione IF per controllare il flusso del programma.

|  |  |
| --- | --- |
| **Operatore** | **Significato** |
| AND | Prodotto logico |
| OR | Somma logica |
| XOR | Somma logica esclusiva |

 

 Ogni operatore dà il risultato indicato di seguito. Nella tabella "T" indica vero e "F" indica falso.

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| **Valori X, Y** | | **Valore restituito dall'operatore logico (risultato)** | | |
| **X** | **Y** | **X AND Y** | **X OR Y** | **X XOR Y** |
| T | T | T | T | F |
| T | F | F | T | T |
| F | T | F | T | T |
| F | F | F | F | F |

 

**Operatori sui bit**

 Gli operatori sui bit eseguono operazioni su ciascun bit delle variabili, per facilitare al mini robot controller il controllo a livello di bit tramite le porte di ingresso/uscita. Per le operazioni su tutti i bit esistono la somma di bit (OR), il prodotto di bit (AND) e la somma di bit esclusiva (XOR); in roboBASIC sono stati aggiunti anche i simboli per spostare (shift) tutti i bit a sinistra (<<) o a destra (>>) e l'operatore “.” per specificare un bit particolare di una variabile.

 Se il valore di A è 33 (in binario 00100001) e il valore di B è 15 (in binario 00001111), gli operatori sui bit danno i risultati della tabella seguente.

|  |  |
| --- | --- |
| **Operatore** | **Risultato** |
| A AND B | 1 (00000001) |
| A OR B | 47 (00101111) |
| A XOR B | 46 (00101110) |
| A << 1 | 66 (01000010) |
| A >> 1 | 16 (00010000) |
| A.0 | 1 (bit 0 di A) |

 Quando in una stessa istruzione sono usati più operatori, le operazioni vengono eseguite nel seguente ordine:

 

① Operatori aritmetici / operatori sui bit

② Operatori relazionali

③ Operatori logici

 

**Numeri, variabili/costanti e altre note di sintassi**

 Poiché roboBASIC è un linguaggio BASIC creato per il controllo hardware, non supporta le variabili o costanti di tipo stringa né le variabili di tipo array che si usano nei normali BASIC.

 

**Tipi numerici**

 I tipi numerici sono byte (BYTE) e intero (INTEGER); l'intervallo di valori per ciascun tipo è indicato nella tabella.

|  |  |  |
| --- | --- | --- |
| **Tipo numerico** | **Dimensione** | **Intervallo** |
| Byte (BYTE) | 1 byte (8 bit) | 0-255 |
| Intero (INTEGER) | 2 byte (16 bit) | 0-65535 |

 

 ***roboBASIC non supporta i numeri negativi.***
Pertanto, aggiungendo il segno + o - davanti a un numero si eseguono operazioni errate o si genera un errore. Inoltre, se durante un'operazione il valore di una variabile dichiarata esce dall'intervallo del suo tipo non viene generato alcun errore, ma il risultato non è corretto; occorre quindi dichiarare sempre un tipo numerico di intervallo adeguato.

 

**Basi numeriche**

 

 Poiché roboBASIC è un linguaggio per il controllo hardware, oltre alla normale notazione decimale, nella scrittura dei programmi può essere comodo esprimere i numeri in altre basi, come l'esadecimale. roboBASIC permette varie notazioni numeriche: binario (Bin), ottale (Oct), decimale (Dec) ed esadecimale (Hex); per usare una base specifica si dichiara la base con il simbolo "&", mentre per i numeri decimali non serve alcuna dichiarazione.

 Il numero 61 decimale si può rappresentare nelle varie basi come nella tabella seguente; se si esce dall'intervallo di cifre utilizzabili nella base scelta si verifica un errore, quindi si devono usare sempre cifre ammesse.

 

|  |  |  |  |
| --- | --- | --- | --- |
| **Base** | **Notazione** | **Cifre utilizzabili** | **Esempio** |
| Binario | &B | 0, 1 | &B111101 |
| Ottale | &O | 0, ... , 7 | &O75 |
| Decimale | nessuna | 0, ... , 9 | 61 |
| Esadecimale | &H | 0, ... , 9, A, ... F | &H3D |

 

**Costanti e variabili**

 Una costante è un valore che non cambia durante l'esecuzione del programma. roboBASIC permette di definire costanti numeriche di tipo byte e intero. Il tipo della costante è determinato automaticamente dall'intervallo del numero usato nella definizione e una costante già definita non può essere ridefinita. Poiché una costante definita viene sostituita direttamente con il valore definito nei punti in cui è usata, non influisce affatto sulla dimensione del programma; definire come costanti i numeri usati di frequente rende comode le modifiche al programma.

 Di seguito alcuni esempi di definizioni di costanti usate di frequente per il controllo hardware del mini robot controller.

 

CONST OFF = 0

CONST 모터\_1 = 3

CONST 모터\_1속도 =
200

 

 Una variabile è il nome di una locazione di memoria per i dati usati dal programma. Poiché il numero di variabili utilizzabili nel mini robot controller è limitato, in base allo scopo d'uso occorre dichiarare le variabili con il tipo che ne riduce al minimo la dimensione.

 Di seguito alcuni esempi di dichiarazioni di variabili usate di frequente nel mini robot controller.

 

DIM 모터\_1\_지연 AS
INTEGER

DIM 센서\_왼쪽 AS
BYTE

 

 Nel dichiarare variabili e costanti si devono rispettare le seguenti regole.

 

 Primo, nei nomi di variabili/costanti si possono usare hangul (hanja), lettere inglesi, numeri e “\_”, e il primo carattere deve essere obbligatoriamente una lettera hangul o inglese.

 

 Secondo, la lunghezza del nome di variabile/costante non può superare 64 caratteri. (Hangul o lettere inglesi, ogni carattere conta come 1.)

 

 Terzo, i nomi di variabili/costanti non possono essere dichiarati due volte con lo stesso nome e, non essendoci distinzione tra maiuscole e minuscole, occorre prestare attenzione.

 

 Quarto, quando si dichiara una costante occorre indicare un valore non superiore a 65535, il limite del tipo intero; se si supera questo valore si verifica un errore.

 

**Specifica del bit**

 roboBASIC permette di manipolare le variabili a livello di bit. Per manipolare i singoli bit si usa l'operatore di specifica del bit (“.”); per le variabili di tipo byte si possono specificare i bit da 0 a 7, per quelle di tipo intero i bit da 0 a 15. Per specificare il bit si deve usare un numero o una costante. Di seguito un esempio di specifica del bit.

 

   DIM A AS INTEGER

   CONST BIT\_2 = 2

 

   A.1 = 1

   A.BIT\_2 = 0

   A.3 = IN(1)     *‘Legge il valore della porta 1 e lo mette nel bit 3 della variabile* *intera* *A*

   OUT 2,
A.1                *‘Invia alla porta 2 il valore del bit 1 della variabile A*

 

**Commenti**

 Per scrivere e gestire il programma in modo efficiente è necessario inserire, qua e là durante la stesura, spiegazioni sul programma. Per i commenti si usa all'inizio ***il simbolo di commento (‘) oppure il comando REMARK***, e non hanno alcun effetto sull'esecuzione del programma.

 

**Istruzione di assegnazione (=)**

 L'istruzione di assegnazione si usa per assegnare un valore a una variabile e utilizza semplicemente il simbolo “=” della matematica. A sinistra del simbolo di assegnazione (=) c'è sempre una variabile, mentre a destra possono esserci una variabile, una stringa, un'espressione di calcolo o una funzione.

 

 Di seguito alcuni esempi di istruzioni di assegnazione.

B                          *‘Assegnazione tra variabili*

A.1 =
1                        *‘Assegnazione a un bit specificato*

A =
ADIN(0)                    *‘Assegnazione di una funzione*

A = 3 \* 2 -
1                    *‘Assegnazione di un'espressione numerica*

A = C + B -
A                  *‘Assegnazione di un'espressione con variabili*

A =
"1"                         *‘Assegnazione del codice ASCII di un carattere*

 

 

**Etichette di riga**

 L'etichetta di riga (Label) si usa per indicare una posizione nel programma e può essere composta da lettere o numeri. Per scegliere il nome di un'etichetta ci sono alcune regole.

 

 Primo, il nome di un'etichetta testuale non può superare 64 caratteri e il primo carattere deve essere hangul o una lettera inglese.

 

 Secondo, dopo il nome di un'etichetta testuale deve sempre essere inserito il simbolo di etichetta (:).

 

 Terzo, il nome di un'etichetta numerica può essere solo un numero compreso tra 0 e 65535 e non si aggiunge il simbolo di etichetta.

 

 Quarto, i nomi delle etichette non possono essere dichiarati due volte con lo stesso nome e, non essendoci distinzione tra maiuscole e minuscole, occorre prestare attenzione.

 

 Le etichette si usano soprattutto con i comandi di controllo del flusso del programma come GOTO o GOSUB. Di seguito un esempio d'uso delle etichette.

 

DIM A AS INTEGER

 

**START:**

          A
= IN(0)

          IF
A = 0 THEN

GOTO **START**

             ELSE

                  
GOSUB 10

          END

          GOTO
**START**

 

**10**OUT 1, 0

DELAY 100

OUT 1, 1

          RETURN

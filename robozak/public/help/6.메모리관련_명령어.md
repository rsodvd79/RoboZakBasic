**Descrizione dei comandi relativi alla memoria**

Il controller miniROBOT può essere considerato un computer miniaturizzato con CPU e memoria integrate; la memoria svolge un ruolo importante per il salvataggio del programma utente, i calcoli, ecc. La memoria collegata esternamente al controller miniROBOT è una EEPROM, usata soprattutto per salvare il programma dell'utente, mentre la memoria che esegue i calcoli si trova all'interno della CPU.

La memoria interna si chiama RAM e, per le caratteristiche della CPU usata nei controller miniROBOT, è detta anche registro (Register). La memoria interna è legata al numero di variabili utilizzabili quando l'utente scrive un programma; *i controller della serie MR-C2000 hanno 30 byte di spazio per le variabili*. Questo significa che si possono usare 30 variabili dichiarate di tipo byte, oppure fino a 15 se si usano solo variabili dichiarate di tipo intero (che occupano 2 byte). *I controller della serie MR-C3000 hanno 256 byte di spazio per le variabili*. Le altre aree della memoria interna sono usate internamente dal controller miniROBOT, quindi non bisogna alterarne i dati alla leggera.

 La memoria esterna (EEPROM) è legata alla dimensione del programma scritto dall'utente; i controller della serie MR-C2000 hanno 4K byte di memoria, mentre quelli della serie MR-C3000, a seconda del modello, hanno 12K byte, 32K byte o 64K byte.

 

  

 

**PEEK()      램읽기()**

Legge il contenuto della memoria interna.

             -
Sintassi inglese : PEEK (*[area RAM]*)

             -
Sintassi coreana : 램읽기 (*[area RAM]*)

 La funzione PEEK(램읽기) legge i dati dalla memoria interna, ma senza conoscere l'esatta struttura della memoria interna non è utilizzabile, quindi non va usata alla leggera.

 *[area RAM]* è un'area che varia a seconda del controller.

 

Controller della serie MR-C2000)

Si può usare un numero compreso tra 0 e 255, una costante o una variabile di tipo byte.

 

Controller della serie MR-C3000)

Si può usare un numero compreso tra 0 e 255, una costante o una variabile di tipo byte.

DIM A AS BYTE

 

A = PEEK(43)                    *‘Carica nella variabile A il valore dell'indirizzo 43 dell'area RAM.*

 

  

 

**POKE   램쓰기**

Scrive dati nella memoria interna.

![](6.메모리관련%20명령어.files/image002.gif)

 

             -
Sintassi inglese : POKE *[area RAM]*, *[dati]*

             -
Sintassi coreana : 램쓰기 *[area RAM]*, *[dati]*

 

![](6.메모리관련%20명령어.files/image003.gif)

Il comando POKE(램쓰기) si usa per scrivere dati nella memoria interna del controller miniROBOT. La funzione PEEK(램읽기) si limita a leggere i dati, mentre il comando POKE(램쓰기) può scrivere direttamente i dati, quindi richiede notevole cautela.

 *[area RAM]*, nei controller della serie MR-C2000, può essere un numero compreso tra 0 e 255, una costante o una variabile di tipo byte; nei controller della serie MR-C3000, un numero compreso tra 0 e 65535, una costante o una variabile di tipo byte. *[dati]* possono essere un numero, una costante o una variabile (comprese quelle di tipo intero).

 

![](6.메모리관련%20명령어.files/image004.gif)

POKE &h40,
100               *‘Scrive il valore 100 all'indirizzo 40 (esadecimale) dell'area RAM.*

 

  

 

**ROMPEEK()           롬읽기()**

Legge i dati dalla EEPROM esterna.

![](6.메모리관련%20명령어.files/image002.gif)

             -
Sintassi inglese : ROMPEEK (*[area ROM]*)

             -
Sintassi coreana : 롬읽기 (*[area ROM]*)

 

![](6.메모리관련%20명령어.files/image003.gif)

Il controller miniROBOT usa una EEPROM per salvare il programma utente o per scopi speciali. La funzione ROMPEEK(롬읽기) e il comando ROMPOKE(롬쓰기), che controllano la memoria esterna, si possono usare per salvare i dati che l'utente vuole conservare in modo permanente. Tuttavia, usando un'area già riservata possono verificarsi errori fatali.  *[area ROM]* può essere un numero, una costante o una variabile.

             -

![](6.메모리관련%20명령어.files/image003.gif)

Il controller miniROBOT usa una EEPROM per salvare il programma utente o per scopi speciali. La funzione ROMPEEK(롬읽기) e il comando ROMPOKE(롬쓰기), che controllano la memoria esterna, si possono usare per salvare i dati che l'utente vuole conservare in modo permanente. Tuttavia, usando un'area già riservata possono verificarsi errori fatali.  *[area ROM]* può essere un numero, una costante o una variabile. *[dati]* possono essere un numero compreso tra 0 e 255, una variabile di tipo byte o una costante.

**TOGGLE          Inversione**

Inverte il segnale di una porta di uscita.

![](TOGGLE.files/image001.gif)

             -
Sintassi inglese : TOGGLE *[numero porta]*

             -
Sintassi coreana : 반전 *[numero porta]*

 

![](TOGGLE.files/image002.gif)

|  |
| --- |
|  |
|  |  |

  
Inverte il segnale di uscita di una porta di uscita. Cioè, se il segnale della porta di uscita è 0 (LOW) diventa 1 (HIGH), se è 1 (HIGH) diventa 0 (LOW).

 *[numero porta]* può essere un numero, una costante, una variabile, ecc.

 

![](TOGGLE.files/image004.gif)

OUT 3, 1          *'Invia il segnale 1 alla porta 3.*

TOGGLE 3        *'Inverte il segnale della porta 3 (da 1 a 0).*
